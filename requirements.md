# Software Requirements

## Project Overview

The AI Meeting Summarizer is a web application that uses
artificial intelligence to summarize meeting notes, identify
important decisions, and extract action items.

## Functional Requirements

- Allow users to enter meeting notes or transcripts.
- Generate meeting summaries using AI.
- Identify important decisions from meeting notes.
- Extract action items, assigned people, and deadlines.
- Allow users to clear meeting notes and results.
- Allow users to copy generated summaries.
- Allow users to download summaries as text files.
- Display error messages when a request fails.
- Prevent users from submitting empty meeting notes.

## Non-Functional Requirements

- The application should respond quickly.
- The interface should be simple and easy to navigate.
- The application should support different screen sizes.
- API credentials must be stored securely.
- The source code should be organized and maintainable.
- The application should handle invalid input properly.

## Assumptions

- Users have access to an internet connection.
- A valid Groq API key is available.
- Meeting notes are provided in text format.
- Users review generated summaries for accuracy.

## Project Scope

The application focuses on summarizing written meeting notes
using artificial intelligence. Audio transcription, user
accounts, and permanent meeting storage are outside the
scope of this project.
